# STUDENT STUDY HABIT ANALYZER USING MACHINE LEARNING

## 1. Introduction
Student Study Habit Analyzer is a Python-based mini project that analyzes student study habits and predicts their academic performance using Machine Learning.

## 2. Objective
- To analyze student study habits.
- To calculate average study hours and marks.
- To analyze attendance and sleeping patterns.
- To predict student performance using Machine Learning.
- To visualize student academic performance.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- CSV File Handling
- Scikit-learn
- Matplotlib

## 4. Machine Learning Algorithm
Random Forest Classifier is used to classify student performance into three categories:
- Good
- Average
- Needs Improvement

## 5. Project Modules
1. CSV File Management
2. Data Analysis
3. Machine Learning Model Training
4. Student Performance Prediction
5. Data Visualization
6. Main Menu System

## 6. Working
The system reads student information from `student_data.csv`. Pandas and NumPy are used for data processing and analysis. A Random Forest model is trained using student study hours, sleep hours and attendance. The trained model predicts the student's performance category.

## 7. Conclusion
This project demonstrates how Python and Machine Learning can be used to analyze student study habits and estimate academic performance. It can be extended with larger datasets and additional student-related features.
